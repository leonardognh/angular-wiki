# Internos do Router

Em **Router Internals**, você estuda o fluxo de navegação do Angular v20+, incluindo features do `provideRouter`, guards/resolvers funcionais, binding de parâmetros para input e decisões de performance. A trilha conecta ergonomia de API com comportamento interno.

## O que você vai ganhar
- Entendimento detalhado da sequência de eventos em cada navegação.
- Critérios para configurar features do Router conforme contexto de negócio.
- Padrões para guards e resolvers funcionais com menor acoplamento.
- Técnicas para reduzir custo de navegação e melhorar experiência percebida.

## Quando entrar nesta trilha
- Quando a navegação está inconsistente, lenta ou difícil de depurar.
- Quando você quer padronizar setup de rotas em apps standalone.
- Quando precisa tratar pré-carregamento de dados com previsibilidade.
- Quando busca melhor equilíbrio entre segurança de rota e performance.
