# SSR e Hidratação

Em **SSR Hydration**, você aprende a entregar experiência inicial rápida no Angular v20+ com renderização no servidor, hidratação, fronteiras de hidratação, `TransferState` e decisões de SEO versus custo de runtime.

## O que você vai ganhar
- Visão de ponta a ponta do pipeline SSR até o cliente hidratado.
- Critérios para definir limites de hidratação e reduzir trabalho no browser.
- Uso estratégico de `TransferState` para evitar requisições duplicadas.
- Ferramentas para balancear SEO, TTFB, interatividade e custo operacional.

## Quando entrar nesta trilha
- Quando páginas críticas precisam carregar rápido em conexões reais.
- Quando SEO orgânico é relevante e a renderização atual não atende.
- Quando você observa duplicação de fetch entre servidor e cliente.
- Quando quer combinar `@defer` com hidratação de forma controlada.
