# Trilha Intermediária

> Você já sabe fazer as coisas funcionarem. Agora é hora de fazer funcionarem **bem**.

## Pré-requisitos

- Ter completado a trilha iniciante (ou equivalente)
- Experiência prática com pelo menos um projeto Angular

## Sequência sugerida

### Fase 1 — Profundidade

1. [RxJS Essencial](/docs/era-classica/rxjs) — Dominando Observables
2. [Reactive Forms](/docs/era-classica/forms) — Formulários complexos
3. [Services & DI (avançado)](/docs/era-classica/services-di) — InjectionToken, hierarquia de injectors

### Fase 2 — Angular Moderno

4. [inject()](/docs/era-transicao/inject-function) — DI funcional
5. [Signal Inputs & Outputs](/docs/era-moderna/signal-inputs-outputs) — Comunicação reativa
6. [Defer Views](/docs/era-moderna/defer) — Lazy loading granular
7. [Resource API](/docs/era-moderna/resource-api) — Dados declarativos
