# Forms no v20+

A trilha de **Forms v20** aprofunda arquitetura de formulários no Angular moderno, cobrindo reactive forms, CVA customizado, validação e performance. Você aprende a construir formulários escaláveis com foco em DX e UX.

## O que você vai ganhar
- Base sólida para modelar formulários complexos com reactive forms.
- Capacidade de criar componentes de formulário reutilizáveis com `ControlValueAccessor`.
- Estratégias para validação consistente, legível e fácil de testar.
- Técnicas para reduzir custo de render e reprocessamento em formulários grandes.

## Quando entrar nesta trilha
- Quando formulários cresceram e ficaram difíceis de manter.
- Quando há inconsistência entre validações de front e regras de domínio.
- Quando você precisa padronizar componentes de entrada reutilizáveis.
- Quando quer melhorar performance de digitação e resposta visual do formulário.
