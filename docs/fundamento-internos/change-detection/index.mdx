# Detecção de Mudanças

A trilha de **Change Detection** cobre como o Angular v20+ propaga atualizações, com foco em custos de render, hooks de renderização, debugging e estratégias zoneless. Você aprende a diagnosticar gargalos e melhorar fluidez de interface com método.

## O que você vai ganhar
- Visão prática do custo de detecção de mudanças em diferentes arquiteturas de componente.
- Uso consciente de hooks de render para observar e otimizar ciclos de atualização.
- Técnicas para investigar glitches visuais e renders inesperados.
- Base para adotar estratégias zoneless com menor risco.

## Quando entrar nesta trilha
- Quando a aplicação apresenta travamentos, repaints excessivos ou UI instável.
- Quando você quer escalar componentes com dados frequentes em tempo real.
- Quando precisa medir impacto de mudanças em performance de render.
- Quando está avaliando migração para padrões mais previsíveis de atualização.
