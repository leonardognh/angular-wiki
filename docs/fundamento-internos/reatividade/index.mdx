# Reatividade

A trilha de **Reatividade** mostra como modelar estado no Angular v20+ com Signals, `resource`, interoperabilidade com RxJS e padrões de composição. O foco é tomar decisões técnicas com mais previsibilidade de render e manutenção.

## O que você vai ganhar
- Fundamentos sólidos para projetar estado com Signals no ciclo de vida atual do Angular.
- Critérios para usar `linkedSignal` e `resource` em cenários reais de UI assíncrona.
- Capacidade de integrar RxJS sem perder ergonomia e legibilidade.
- Padrões para separar estado de feature, estado derivado e efeitos colaterais.

## Quando entrar nesta trilha
- Quando seu projeto depende de múltiplas fontes assíncronas e o estado está confuso.
- Quando você quer reduzir boilerplate de subscriptions e sincronização manual.
- Quando precisa definir um padrão consistente entre Signals e RxJS.
- Quando está planejando evoluir arquitetura para melhor desempenho de renderização.
