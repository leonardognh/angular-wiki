# Runtime de Template

A trilha de **Template Runtime** explica como o Angular v20+ compila, agenda e executa templates com recursos modernos como control flow, `@defer`, projeção de conteúdo e renderização dinâmica. Você passa a enxergar o template como runtime, não só sintaxe.

## O que você vai ganhar
- Modelo mental de compilação e execução de templates no Angular atual.
- Critérios para escolher entre control flow nativo, projeção e renderização dinâmica.
- Prática para usar `@defer` com foco em UX e custo de carregamento.
- Leitura mais rápida de problemas de template em performance e comportamento.

## Quando entrar nesta trilha
- Quando componentes ficaram complexos e difíceis de evoluir.
- Quando você quer melhorar tempo de carregamento percebido sem hacks.
- Quando precisa escalar componentes reutilizáveis com múltiplos slots e contextos.
- Quando quer dominar padrões modernos além de `*ngIf` e `*ngFor`.
