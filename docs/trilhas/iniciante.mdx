# Trilha Iniciante

> De zero a uma app Angular funcional. Sem pressa, sem pular etapas.

## Pré-requisitos

- HTML, CSS e JavaScript básico
- TypeScript básico (tipos, interfaces, classes)
- Node.js instalado

## Sequência sugerida

### Fase 1 — Fundamentos

1. [Components](/docs/era-classica/components) — Sua primeira peça de UI
2. [Templates](/docs/era-classica/templates) — HTML dinâmico com Angular
3. [Data Binding](/docs/era-classica/data-binding) — Conectando dados com a view

### Fase 2 — Construindo blocos

4. [Directives](/docs/era-classica/directives) — Comportamento customizado no DOM
5. [Pipes](/docs/era-classica/pipes) — Transformando dados no template
6. [Comunicação entre Components](/docs/era-classica/component-communication) — Input, Output
7. [Lifecycle Hooks](/docs/era-classica/lifecycle) — O ciclo de vida de um component

### Fase 3 — Infraestrutura

8. [Services & DI](/docs/era-classica/services-di) — Lógica compartilhada e injeção de dependências
9. [Routing](/docs/era-classica/routing) — Navegação entre páginas
10. [HttpClient](/docs/era-classica/http) — Comunicação com APIs
11. [Formulários](/docs/era-classica/forms) — Capturando dados do usuário

### Fase 4 — O Angular de hoje

12. [Standalone Components](/docs/era-transicao/standalone-components) — O modelo moderno
13. [Novo Control Flow](/docs/era-moderna/control-flow) — @if, @for, @defer
14. [Signals](/docs/era-moderna/signals) — Reatividade moderna

:::tip[Dica]

Não tente memorizar tudo na primeira vez. Faça os desafios de cada tópico e volte pra reler quando precisar. Aprender framework é iterativo.

:::
