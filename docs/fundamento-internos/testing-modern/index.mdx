# Testing Moderno

A trilha de **Testing Modern** organiza práticas de teste no Angular v20+ com foco em TestBed atual, Harnesses, cenários com Signals e testes de Router/HTTP. O objetivo é aumentar confiança de entrega com testes úteis e sustentáveis.

## O que você vai ganhar
- Critérios para escolher nível de teste e reduzir flakiness.
- Uso moderno de TestBed com setup mais enxuto e expressivo.
- Padrões com Harness para desacoplar teste de detalhe visual frágil.
- Estratégias para testar fluxos com Signals, Router e HTTP de forma integrada.

## Quando entrar nesta trilha
- Quando sua suíte está lenta, frágil ou com baixa cobertura efetiva.
- Quando times diferentes escrevem testes sem padrão comum.
- Quando mudanças de UI quebram testes por acoplamento a implementação.
- Quando você precisa aumentar confiança em refactors de features críticas.

## Como estudar (ordem sugerida)
1. [Uso Moderno do TestBed](/docs/fundamento-internos/testing-modern/testbed-modern-usage)
2. [Padrões com Component Harness](/docs/fundamento-internos/testing-modern/component-harness-patterns)
3. [Testes com Signals](/docs/fundamento-internos/testing-modern/signals-testing)
4. [Testes Modernos de Router e HTTP](/docs/fundamento-internos/testing-modern/router-http-testing-modern)

:::tip[Dica]
Priorize testes que capturam comportamento de negócio; quantidade sem foco não aumenta confiança real.
:::
