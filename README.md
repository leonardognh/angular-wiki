# Angular Wiki

Essa documentação foi criada com [Docusaurus](https://docusaurus.io/).

O site usa **versionamento do Docusaurus**:

- **Angular 16** — árvore viva em `docs/` (padrão ao abrir a documentação).
- **Angular 15** — snapshot em `versioned_docs/version-15.0.0/` (corte `15.0.0`).

Para congelar a linha atual numa nova versão no futuro: `npm run docusaurus docs:version <rótulo>` (ex.: `16.0.0` quando migrar a árvore viva para v17).

### Instalação

```
$ npm i
```

### Rodar Local

```
$ npm run start
```

### Build

```
$ npm run build
```
