# Era Moderna (v17+)

> O Angular do futuro — que já é presente. Signals, novo control flow, e um framework que finalmente ficou simples sem perder a potência.

## Sobre esta era

A partir do Angular 17, o framework deu um salto conceitual. **Signals** substituem boa parte do RxJS para estado local. O **novo control flow** (`@if`, `@for`, `@defer`) troca diretivas estruturais por sintaxe nativa. **Zoneless change detection** promete performance sem Zone.js.

Essa não é mais uma "feature experimental". É o Angular padrão.

## O que você vai aprender

- **Signals** — reatividade granular sem RxJS
- **Signal Inputs & Outputs** — input(), output(), model()
- **Novo Control Flow** — @if, @for, @switch, @defer
- **Defer Views** — carregamento lazy no template
- **Signal Queries** — viewChild(), viewChildren()
- **Zoneless** — change detection sem Zone.js
- **SSR & Hydration** — server-side rendering com rehydration
- **Resource API** — carregamento de dados declarativo
- **LinkedSignal** — estado derivado mutável

## Pra quem é esta seção

- Devs começando projetos novos com Angular 17+
- Devs migrando projetos existentes pro modelo moderno
- Devs que querem entender o futuro do framework
