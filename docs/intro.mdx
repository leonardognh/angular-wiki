# Angular Wiki 🇧🇷

> Documentação Angular em português, feita por devs, para devs. Sem corporativês, sem enrolação.

## O que é isso aqui?

Isso é um guia prático e completo sobre Angular — desde o NgModule clássico até Signals e o futuro zoneless. Tudo em pt-BR, com código em inglês (porque é assim que a gente escreve no dia a dia).

A ideia é simples: se você tá começando, vai aprender do zero. Se já manja, vai entender como e por quê as coisas mudaram — e o que fazer a respeito.

## Como a documentação é organizada

Dividimos o Angular em **3 eras** que refletem a evolução real do framework:

### Era Clássica (v2–14)

O Angular que todo mundo conhece. Modules, decorators, class-based services, RxJS como coluna vertebral. Se você trabalha com um projeto que já existe há alguns anos, provavelmente vive aqui.

### Era Transição (v14–16)

Standalone components, `inject()`, functional guards. O Angular começou a questionar suas próprias decisões e simplificar. É o período em que o novo e o antigo convivem.

### Era Moderna (v17+)

Signals, novo control flow (`@if`, `@for`, `@defer`), zoneless. O Angular do futuro — que já é presente.

### Complementos

CLI, arquitetura de projeto, performance, testes, RxJS vs Signals, padrões de estado. Coisas que cortam todas as eras.

## Formato de cada tópico

Todo tópico segue um formato consistente:

| Seção                   | O que você encontra                                |
| ----------------------- | -------------------------------------------------- |
| **O que é**             | Explicação direta em 2-3 frases                    |
| **Pra que serve**       | Qual problema resolve                              |
| **Quando usar**         | Cenários práticos                                  |
| **Quando NÃO usar**     | Cenários onde não faz sentido                      |
| **Antes vs Depois**     | Como se fazia antes vs como se faz agora           |
| **Alternativas**        | Outras formas de resolver o mesmo problema         |
| **Exemplo funcional**   | Código real, mínimo e rodável                      |
| **Armadilhas comuns**   | Erros que todo mundo comete                        |
| **Por baixo dos panos** | Como funciona internamente (opcional, collapsible) |
| **No mundo real**       | Mini-cases de apps em produção                     |
| **Desafios**            | 🟢 Iniciante · 🟡 Intermediário · 🔴 Avançado      |
| **Links úteis**         | Docs oficiais e RFCs relevantes                    |

## Pré-requisitos

- Conhecimento básico de **HTML, CSS e JavaScript/TypeScript**
- Um editor de código (recomendamos VS Code com a extensão [Angular Language Service](https://marketplace.visualstudio.com/items?itemName=Angular.ng-template))
- Node.js instalado (LTS)
- Vontade de aprender e paciência pra errar

## Convenções

- Termos técnicos ficam em inglês (component, service, pipe, signal, etc.)
- Explicações ficam em pt-BR
- Dicas aparecem em blocos de destaque
- Avisos importantes aparecem em blocos de warning
- "Por baixo dos panos" são blocos colapsáveis pra quem quer ir fundo
