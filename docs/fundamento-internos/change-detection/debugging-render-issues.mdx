# Debug de Problemas de Renderização

## Contexto técnico

Bugs de UI “fantasma” quase sempre são: estado não atualizado, dependência não rastreada, async fora do ciclo, ou erro silencioso no template.

## O que observar internamente

- Sinais lidos fora de contexto reativo.
- `async`/`Promise` sem integração correta.
- Diferenças SSR vs browser.

## Quando ajuda

- Quando a UI “às vezes” não atualiza.

## Quando evitar

- Não é tópico para evitar — é operação.
