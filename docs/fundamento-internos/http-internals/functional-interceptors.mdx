# Interceptors Funcionais

## Contexto técnico

Interceptors funcionais são a forma moderna de compor políticas HTTP sem classes.

## O que observar internamente

- Ordem e idempotência.
- Retry seguro.

## Quando ajuda

- Auth, tracing, normalização de erro.

## Quando evitar

- Lógica ultra específica de um endpoint (pode ficar no service).

## Exemplo real

```ts
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(SessionService).token();
  return next(token ? req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }) : req);
};
```

## Checklist rápido

- [ ] Ordem documentada.
- [ ] Sem retry cego em POST sensível.
