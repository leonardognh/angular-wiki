# Reactive Forms Moderno

## Contexto técnico

Reactive Forms no v20+ funciona melhor com `nonNullable`, tipagem explícita e validação organizada.
O foco é reduzir `any` e estado implícito.

## O que observar internamente

- `updateValueAndValidity` e performance.
- Validação async e cancelamento.

## Quando ajuda

- Formulários médios/grandes.

## Quando evitar

- Form trivial (template-driven pode bastar).

## Exemplo real

```ts
readonly form = this.fb.group({
  email: this.fb.nonNullable.control('', { validators: [Validators.required, Validators.email] }),
});
```
